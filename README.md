# Portafolio Web – Crystal

La construcción de este portafolio web permitió fortalecer competencias clave en el diseño de interfaces adaptables, la organización del contenido con **HTML** y la aplicación de estilos mediante **CSS**. Además, se potenció el uso de **Git** como herramienta profesional de control de versiones y se adquirió práctica en la publicación de proyectos en línea.  

El resultado es un portafolio accesible, funcional y bien documentado, que refleja el dominio de los aprendizajes alcanzados y respalda el desarrollo profesional en el ámbito del desarrollo web.

## Contenido principal
- `index.php` → Página inicial
- `CSS/` → Estilos
- `javacrit/` → Scripts (JavaScript)
- `img/` → Imágenes
- `login.php`, `register.php`, `logout.php` → Autenticación de usuarios
- `conexion.php` → Conexión a base de datos
- `check_session.php` → Validación de sesión
- `download.php` → Descarga de archivos
